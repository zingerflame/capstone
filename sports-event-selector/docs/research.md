# Research rationale and primary sources

Research checked on **24 October 2026**. Thirteen primary academic sources are linked below, including recent sports spotting work and foundational methods. This is an engineering literature review, not a claim that the implemented baseline reproduces their architectures or published results. No patent clearance or novelty opinion is implied; the requested source minimum is met with papers and technical reports.

## Recommendation

The requested task is closest to **precise event spotting**, with a custom class-agnostic frame-selection output. Whole-video action recognition is too coarse; temporal localization detects intervals, whereas this system needs a few frame anchors. E2E-Spot, T-DEED and recent precise spotting work are therefore stronger conceptual matches than simply applying a large video classifier. The fixed 10-frame interface is preserved, despite the literature's evidence that longer temporal context helps.

Start with the implemented small CNN/Transformer to validate sampling, teacher quality, voting and losses. Then replace the scene encoder with a pretrained high-resolution representation and benchmark against E2E-Spot/T-DEED-style temporal models. VideoMAE V2 and InternVideo2 are candidate representation sources, not dependencies already integrated here. The ten-position selection head, scoreboard branch and global voting can remain unchanged after a careful feature-interface adaptation.

The truncated distance target, six-positive cap, forced endpoints, normalized overlap vote, sequence grouping and cardinality surrogate are **custom choices for this request**. None is claimed to be established by one cited paper. Context-aware spotting losses motivate softer temporal supervision; they do not validate these exact weights or the ±3 filtered-frame radius.

## Dataset strategy

SoccerNet is a natural soccer starting point. Its [official task page](https://www.soccer-net.org/tasks/action-spotting) documents broadcast action spotting and its action classes. GolfDB supplies a complementary, finely timed golf task. Neither supplies a single all-sport, all-pass commentary dataset. Use the manifest interface for the chosen database's downloaded files or direct media URLs, and obtain fresh teacher annotations for the desired definition of “commentate-able.”

Scoreboard pixels are included because the user requested channel context. The papers above do not establish that our particular crop branch improves accuracy. Measure this with an ablation: scene-only versus scene+scoreboard, including games where the graphic disappears, changes position, or lags the play. A score change should corroborate an action, not create a positive label by itself.

## Experiment plan

1. Audit sampling recall: on manually annotated short clips, check whether the 10–20 FPS filter preserves useful evidence. Separate fast racket contacts from slower possession changes.
2. Audit teacher labels by sport and channel, including routine passes, no-action periods, replays, ads and camera cuts. Report inter-reviewer disagreements and teacher misses.
3. Compare uniform sampling, delta-only sampling and learned selection under equal output budgets.
4. Compare binary targets versus the ±3 distance target, then add global count, coverage and duplicate penalties one at a time.
5. Compare scene-only versus scoreboard fusion and low-resolution scratch features versus pretrained features.
6. Hold out entire matches and at least one channel layout. Report frame matching at tolerances 0–3, seconds-based errors, event recall, retention ratio, and throughput. Report class-aware mAP only if semantic-class prediction is added.
7. Investigate a learned pairwise event-link/boundary head if heuristic 2/3-frame grouping becomes the limiting factor. Compare longer context separately; keep the requested ten-frame baseline intact for attribution.

No real-data accuracy, superiority, sample complexity or training cost is asserted before these experiments are run.
